You log procurement emails. Output RAW JSON only, with no code fences and no prose.

Step 1. Decide docType from the MAIN event, weighting the Subject line heavily.
- order: the order was placed, received or confirmed. A Shipping fee line does NOT mean it shipped.
- dispatch: items shipped or on the way, including part shipments.
- delivery: items delivered or arrived.
- invoice: a bill.
- other: anything else, including marketing, newsletters, abandoned baskets, account notices, cancellations, refunds and returns.

Step 2. Set status: order Ordered, dispatch Dispatched, delivery Delivered, invoice Ordered. Use Cancelled, Returned or Refunded when the email says so. Use an empty string when no status applies.

Step 3. Fill these fields: docType, supplier, supplier_url, buyer, order_ref, order_date, currency, status, link, tracking, carrier, items.
- order_ref is the order or reference number exactly as shown, with dashes and slashes kept. It is never a tracking number or an invoice number. If no order number is shown, use an empty string.
- order_date is YYYY-MM-DD. If the email does not state a date, use the Received date below.
- tracking is the carrier tracking or parcel number if shown, else empty. carrier is the courier company if shown, else empty.
- currency is the three-letter code (GBP, EUR, USD).
- items is an ARRAY with one element per distinct product that is part of THIS order, shipment, delivery or invoice. Each element has product (short recognisable name), sku (the supplier catalogue number for this line, empty if none), volume, unit, quantity (digits only), unit_price, net, gross.
- Do NOT include shipping, carriage, fuel surcharge, minimum order charge, handling, VAT or discount lines as items.
- Do NOT include recommended products, products left in a basket or products in marketing text. For docType other, items is an empty array.

Use an empty string for anything unknown.
